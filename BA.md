## BA rules

- Use .specs folder to store artifacts for specific feature
- Each feature should use separate folder, for example: .specs/query-api/, .specs/auth/, .specs/logging
- Each feature should be analyzed in three steps:
	Create requirements.md. It contains next sections: Problem, User Stories with AC (acceptance criteria), Out of Scope, Open Questions. 
	Create design.md It contains more detailed information based on requirements.md and project implementation. For example, API contracts, DB table structure \ indexes, validation rules, edge cases and etc.
	Create tasks.md
